# Guía interactiva de lectura para batería - Musicala

App web estática y autocontenida.

## Abrir localmente
Abre `index.html` en cualquier navegador moderno.

## Subir a Firebase Hosting
Puedes usar esta carpeta como raíz pública o copiar sus archivos dentro de tu carpeta `public`.

Archivos:
- index.html
- styles.css
- script.js

No requiere dependencias ni instalación.
